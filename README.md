# Librairie de création de géométries

Auteur : Safira Said 
<br> D'après le cours de *Design Pattern* de Michael Borne - [les patrons de conception](https://mborne.github.io/cours-patron-conception/) 
<br> Édité en novembre 2026

## Description

Le travail a été réalisé dans le cadre du TP du cours Design Pattern du Master 2 Géomatique parcours TSI. Cette mini-librairie contient des fonctions et des classes pour l'implémentation de géométries ainsi que la vérification des fonctions via des tests unitaires pour fluidifier l'apport de fonctionnalités. 

Les scripts ont été entièrement conçu en TypeScript sous forme de fichiers .ts pour l'implémentation des classes ainsi que la déclaration des fonctions et .spec.ts pour les tests unitaires.
